# Foseer Deployment Guide

This guide provides comprehensive instructions for deploying the Foseer editorial website to various platforms.

## Prerequisites

- Node.js 18.17.1+ or Node.js 20.3.0+ or Node.js 21.0.0+
- npm or yarn

## Build Process

```bash
# Install dependencies
npm install

# Build the site
npm run build

# Preview the built site
npm run preview
```

The build process generates static files in the `dist/` directory.

## Deployment Platforms

### Netlify

1. Connect your repository to Netlify
2. Set build command: `npm run build`
3. Set publish directory: `dist`
4. Environment variables:
   - `SITE`: `https://your-domain.com`

### Vercel

1. Import your project from GitHub
2. Set build command: `npm run build`
3. Set output directory: `dist`
4. Environment variables:
   - `SITE`: `https://your-domain.com`

### Cloudflare Pages

1. Connect your repository
2. Set build command: `npm run build`
3. Set build output directory: `dist`
4. Environment variables:
   - `SITE`: `https://your-domain.com`

### AWS S3 + CloudFront

1. Build the site: `npm run build`
2. Upload `dist/` folder to S3 bucket
3. Configure CloudFront distribution with:
   - Origin: S3 bucket
   - Viewer Protocol Policy: Redirect HTTP to HTTPS
   - TTL settings for optimal caching

### Docker

```dockerfile
# Multi-stage build for production
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx/nginx.conf /etc/nginx/nginx.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

Build and run:
```bash
docker build -t foseer .
docker run -p 8080:80 foseer
```

## Environment Variables

- `SITE`: Your production domain (e.g., `https://foseer.com`)
- `ANALYTICS_GOOGLE_ID`: Google Analytics tracking ID (optional)

## Performance Optimization

### Caching Headers

The site includes optimized caching headers for:
- CSS/JS: 1 year
- Images: 1 year
- HTML: 1 month
- Fonts: 1 month

### Compression

- Gzip compression enabled for all text-based assets
- Brotli compression recommended for modern browsers

### Security Headers

- Content Security Policy (CSP)
- X-Frame-Options
- X-Content-Type-Options
- X-XSS-Protection
- Referrer-Policy

## SEO Configuration

### Sitemap

- Automatically generated by `@astrojs/sitemap`
- Located at `/sitemap-index.xml`
- Includes all pages, posts, and categories

### RSS Feed

- Available at `/rss.xml`
- Includes all blog posts with metadata
- Updated automatically on build

### Robots.txt

- Configured for optimal search engine crawling
- Allows RSS feed and sitemap
- Blocks admin and system paths

## Troubleshooting

### Common Issues

1. **Build fails**: Check Node.js version compatibility
2. **Images not loading**: Verify image paths and formats
3. **CSS not applying**: Check Tailwind build process
4. **SEO issues**: Verify meta tags and sitemap generation

### Debug Commands

```bash
# Check build output
npm run build -- --verbose

# Validate sitemap
curl https://your-domain.com/sitemap-index.xml

# Validate RSS feed
curl https://your-domain.com/rss.xml

# Check robots.txt
curl https://your-domain.com/robots.txt
```

## Security Considerations

### HTTPS

- Force HTTPS redirect configured
- SSL certificate required for production

### Content Security Policy

- Restrictive CSP headers prevent XSS attacks
- Only allow trusted domains for external resources

### File Permissions

- Ensure proper file permissions on deployed files
- Restrict access to sensitive files (.env, config files)
